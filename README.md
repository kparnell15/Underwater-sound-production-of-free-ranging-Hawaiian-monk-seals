

# Data Accessibility 

This repository includes two folders: (1) DFA Analysis, which contains the acoustic measurement .csv file and .R file used for vocal classification, and (2) rehmsvocaltrends, which includes detection/classification .cvs files from all recording sites and the .Rmd and .Rproj files for temporal pattern analyses. While raw acoustic recordings are not publicly archived due to file size (> 20 TB), all processed data used in the analysis are provided in accordance with the Royal Society’s open data policy and licensing guidelines.
